# Source artwork

Original low-resolution images, superseded logo exports, template SVGs, and retired flower artwork are retained here for reference. This directory is outside Vite's public directory and is not copied into production builds.

The assets used by the website are under `public/images/`, grouped into `agendas`, `events`, `guests`, and `logos`. Editing source artwork here does not automatically regenerate those exports. Refer to `docs/design/` for provenance and enhancement prompts.
